# VieNeu v3 Turbo catalog

`voices_v3_turbo.json` is copied unchanged from the official `vieneu==3.8.3`
wheel on [PyPI](https://pypi.org/project/vieneu/3.8.3/).

Wheel SHA-256: `7388d166e65746f5bb075bf8094d324f8131a82393680b712260d6f2f983ef06`.

The upstream Apache-2.0 license is included as `LICENSE`. Source:
[pnnbao97/VieNeu-TTS](https://github.com/pnnbao97/VieNeu-TTS).

FlowKit uses this catalog when the optional source checkout is absent. Voice
names, embeddings and codes stay unchanged, preserving saved voice IDs and demo
cache keys. Reading the catalog does not import VieNeu or load its model.
