## Requirements and installation

- Apple Silicon Mac (M1 or later) or Intel Mac, macOS 13 or later.
- Choose `arm64` for Apple Silicon and `x64` for Intel. In **About This Mac**,
  check the **Chip** or **Processor** field if unsure.
- Open the DMG, then drag **FrameWeaver** into **Applications** and open it.
- Connect your own AI accounts. Google Flow requires Chrome, the bundled extension,
  and a signed-in Flow tab; use the application's extension installation menu.
- The app bundles Electron, Python 3.12, FFmpeg/ffprobe 8.1, and Vietnamese/CJK fonts.
  No terminal setup of Python or FFmpeg is needed for the core app.

If a source installation is already using ports 8100 or 9222, quit that session
before starting the desktop app. The desktop app can also offer to open a compatible
running session, which continues to use that session's data.

## Chrome extension for Google Flow

The extension is already inside both desktop apps. You can use the separate ZIP
above or the app menu **Ứng dụng → Cài extension Google Flow…** to obtain it.

1. Extract the ZIP; keep its `extension` folder.
2. Open `chrome://extensions` in Chrome and enable **Developer mode**.
3. If an older FrameWeaver extension is installed, remove that copy so only one
   FrameWeaver extension is enabled.
4. Click **Load unpacked** and select the `extension` folder containing `manifest.json`.
5. Start FrameWeaver, sign in at [Google Flow](https://flow.google.com/) in Chrome,
   and keep the Flow tab open. Refresh the Flow tab if the extension was just installed.
6. Confirm that FrameWeaver reports the extension as connected.

The ZIP includes the unchanged extension code from the frozen desktop snapshot,
installation instructions in English/Vietnamese, and license/attribution notices.
It contains no account credentials or private signing key. The two earlier source
preview releases also retain their own extension ZIPs.

## Version scope

Application code is frozen at the bundle packaged on **17 October 2026**.
Both architecture installers were completed on **20 October 2026**. The Intel
edition reuses the same backend, dashboard, Electron wrapper, extension and fonts;
only native runtimes/libraries and the user guide's CPU label were adapted. The
shared application payload hash is recorded in the Intel manifest. Later source
changes are reserved for future installers.

This is a **desktop binary release**. Its tag records the publication and release
documentation. The repository source and GitHub's automatic **Source code** archives
are a separate source preview and do not reproduce this frozen desktop installer.
For this app, download the DMG and use these version-specific notes; the repository
README and feature guides continue to describe the source workflow.

## Data and optional engines

- Desktop projects, settings, and output live under
  `~/Library/Application Support/FrameWeaver`.
- The app does not automatically import a source installation's database.
- The installer does not contain the maintainer's projects, generated media,
  account cookies, API keys, or private signing material.
- Whisper, TTS models, ProPainter, and the Muse gateway require separate setup.
  This beta does not include the newer model installation/storage-management UI.
- New projects in this beta require the Google Flow connection to be ready.
- AI generation uses each user's service account and applicable provider credits.

## Checks and beta limits

- App and DMG: Developer ID signatures verified, Apple notarization **Accepted**,
  tickets stapled and validated, Gatekeeper accepted.
- DMG integrity and final release checksums verified, including the app inside it.
- Previous tests on the build Mac covered a clean desktop database, video import,
  timeline persistence, preview, H.264/AAC export, Vietnamese/Chinese text, and shutdown.
- The Intel edition ran through Rosetta: Electron reported `x64`, Python `x86_64`, the
  dashboard opened, a four-second video was imported, the timeline was saved/reloaded,
  and H.264/AAC export preserved its duration, audio, and Vietnamese/Chinese text.
  Its 64 native binaries were checked for architecture, minimum macOS, and external
  build-machine library paths.
- Not yet verified on a second Mac without development tools or with large-model
  inference through the desktop runtime. The Intel edition has not been tested on
  a physical Intel Mac; optional engines need their own Intel compatibility checks.
  This remains a beta, not a stable release.
- This release contains no Windows or Linux installer.
