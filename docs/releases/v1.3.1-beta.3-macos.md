## Included changes

- **ChatGPT component installation in Settings**: download the pinned official
  OpenAI Codex CLI, verify SHA256, sign in through the browser, and optionally
  test a small AI request. No Node.js, Terminal or administrator installation.
  Progress/cancel/retry and exact source/destination are visible. Existing CLI
  installations keep priority. First-launch verification allows time for macOS
  executable checks and reports startup errors separately from download errors.
- **Reload interface** in the top bar, including inside the desktop window.
- **Shared live extension health**: a connection check updates the sidebar
  immediately; status refreshes after disconnects/reconnects without manual reload.

- **Check connection** in Settings and the setup guide: checks the backend,
  a fresh extension reply, and Flow tab/session state separately. Explains old
  extensions, sleeping/loading tabs, and missing Flow context without generating media.
- **Extension 0.3.6**, included in both apps and the separate ZIP.
- **Muse integration in both Mac apps**: script planning, reference/scene images,
  and video from a starting image. Providers are selected separately in Studio.
  The optional muse2api gateway and your account are set up separately; they
  are not preinstalled or signed in. See [Muse setup](../MUSE.md)
  ([Tiếng Việt](../MUSE.vi.md)).
- Audio-library discovery ignores macOS `._…` resource-fork metadata on external volumes.

The bundled core includes Electron, Python 3.12, FFmpeg/ffprobe 8.1 and
Vietnamese/CJK fonts. Whisper, TTS and ProPainter models are not bundled. Settings includes model/storage controls; separate inference environments still
require setup and have not been validated on both packaged architectures.

## ChatGPT setup

See [English](../CHATGPT-DESKTOP.md) or [Tiếng Việt](../CHATGPT-DESKTOP.vi.md).
Install the optional component in Settings, then sign in through OpenAI's browser
login. It is downloaded only on request and is not included in the DMG. Existing
Codex installations keep priority. **Test AI** uses your account's quota.

## Install or upgrade

1. Check **About This Mac** and choose `arm64` for an Apple chip or `x64` for Intel.
2. Quit the earlier app. Open the DMG and drag FrameWeaver into Applications,
   replacing the previous application when upgrading. User data stays under
   `~/Library/Application Support/FrameWeaver`; the app does not import a source
   installation's database automatically. Back up important projects before an upgrade.
3. For Google Flow, get extension 0.3.6 from the ZIP or the app menu
   **Ứng dụng → Cài extension Google Flow…**. Extract it, enable Developer mode at
   `chrome://extensions`, and **Load unpacked** the `extension` folder. Keep one
   FrameWeaver bridge enabled; an extension pointing at another folder still reads
   that folder's files.
4. Sign in at [Google Flow](https://flow.google.com/), reload the Flow tab, then
   use **Settings → Google Flow connection → Check connection**. This check does
   not generate images/clips or consume credits.
5. For Muse, follow the gateway/account steps in the [Muse guide](../MUSE.md),
   then select Muse for the desired stages. Muse generation goes through its
   gateway; Flow generation uses the Chrome extension. **Creating a new project
   in this beta still requires a working Flow connection.**

Quit any source session occupying ports 8100/9222 before starting a separate desktop
session. No maintainer database, generated media, account cookies, API keys or private
signing material are included. Each user connects their own service accounts.

## What was verified

- App and DMG signatures, Apple notarization, stapled tickets, Gatekeeper,
  DMG integrity, architecture, and final manifest hashes.
- Both runtimes: Python startup, local source registration, saved/reopened timeline,
  boxed title controls, a four-second H.264/AAC export, and Vietnamese/Chinese text.
- 181 focused unit tests and dashboard build/lint. Both packaged runtimes also
  passed real official Codex download/hash/extraction/version checks and managed CLI discovery.
- Intel ran through **Rosetta on Apple Silicon**, including x86_64 Python/FFmpeg.
  **No physical Intel Mac was tested.** Optional inference engines need separate compatibility checks.

Not yet verified on a second Mac without development tools, with heavy-model
inference in the desktop runtime, or for every live Muse/Flow account. This is a
**beta**, not a stable release. No Windows/Linux installer is included here.

The architecture-independent app payload is the same in both editions:
`aefc08caedb6b383396345976993400be69bd10d5fdba6e6bffba305b2557f48`.
Native runtimes differ. Verification scope and notarization receipts are recorded
in `VERIFICATION.json` and `NOTARIZATION-STATUS.json` attached to the release.

## Assets and checksums

| Files | Purpose |
| --- | --- |
| `FrameWeaver-1.3.1-beta.3-macOS-{arm64,x64}.dmg` | Signed, notarized installers |
| `FrameWeaver-1.3.1-beta.3-macOS-{arm64,x64}-media-sources.zip` | Matching FFmpeg/x264/pkgconf source archives, checksums and build recipes |
| `FrameWeaver-1.3.1-beta.3-macOS-{arm64,x64}-manifest.json` | Runtime hashes, sizes and signing state |
| `FrameWeaver-1.3.1-beta.3-extension.zip` | Matching extension 0.3.6, instructions and notices |
| `SHA256SUMS.txt` / `SHA256SUMS-x64.txt` | ARM / Intel installer and media-source hashes |
| `SHA256SUMS-extension.txt` | Extension ZIP hash |
| `SHA256SUMS-all.txt` | All non-checksum downloadable asset hashes |
| `RELEASE-NOTES-vi.md` / `RELEASE-NOTES-vi-x64.md` | Vietnamese instructions and limits |
| `VERIFICATION.json` / `NOTARIZATION-STATUS.json` | Checks performed and Apple notarization IDs |

Put the ARM DMG, its media-source ZIP and `SHA256SUMS.txt` together, then run:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

For Intel use `SHA256SUMS-x64.txt` with the Intel files. For the extension use
`SHA256SUMS-extension.txt`. Use `SHA256SUMS-all.txt` only after downloading all
non-checksum assets listed in it. Each entry should report `OK`.

The media-source archives accompany the bundled GPL FFmpeg/x264 components;
component licenses are also included in the applications.

## Version and source scope

This is a **desktop binary release**. Its tag records publication and documentation.
The repository source preview and GitHub's automatic **Source code** archives are
separate and do **not** reproduce this packaged desktop snapshot. In particular,
this documentation publication does not add the desktop Muse or ChatGPT installer implementation to
the public source preview. Download the DMG for the features described here.
