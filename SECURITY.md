# Security

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/phucnguyentvp1/frameweaver/security/advisories/new)
for a reproducible security issue. Include affected versions, a minimal
reproduction, expected impact, and a suggested fix if available.

Do not include real API keys, session cookies, OAuth tokens, signing keys, signed
media URLs, or personal project databases in a public issue or pull request.
Redact those values from logs and screenshots.

This preview is intended for local desktop use. The default backend and bridge
bind to localhost. A public or shared deployment needs its own access-control
review and is outside the verified installation described in this repository.

Optional integrations, browser services, models, and bundled assets retain their
own policies and license terms. See `THIRD_PARTY_NOTICES.md`.

No response-time or support SLA is promised for the preview release.
